What you will see

The new error message, piece by piece

Today the app only says Chapter pages failed: HTTP 403. Comix K adds 4 pieces after it. Each piece answers 1 question.

Chapter pages failed: HTTP 403 · reply: {"error":"captcha_required"} · checked loads: 0 · puzzle page: no · ua: app
HTTP 403Already there. The site said "no".
replyWhy the site said no, in its own words. First 200 characters. Task 3.
checked loadsHow many page loads the app let the extension inspect. 0 means the app never shows it any. Task 5.
puzzle pageDid the site's own puzzle page start loading? Task 5.
uaWhich browser name we sent. "app" means Tachimanga's own, "forced" means ours. Task 4.

Words on this page

7 words you need first

User agent (UA)
A name tag every browser sends, like "I am Safari on iPhone". Comix blocks name tags it does not like.
Cloudflare pass
A cookie you get after the "Just a moment..." check. It only works with the same name tag you had when you got it.
Package name
The extension's unique app name, like …en.comixk. Two extensions with the same one cannot both be installed.
Source ID
A number Tachimanga uses to link your library and settings to the extension. Changing it later disconnects them.
Signing key
A private file that proves updates come from you. Lose it, and every update needs uninstall and reinstall.
Repo branch
A separate branch called repo that only holds the published list. Tachimanga reads this list.
index.pb
The extension list file in keiyoushi's current format. Its link is what you paste into Tachimanga.
How it fits together

From a push on your Mac to a chapter on your iPhone

  • Reused as is. keiyoushi's build tools, the whole Comix code, its publish script, and its exact GitHub Action versions.
  • New. The 3 probe changes, an identity check, 2 test files, and a shorter one-job workflow.
  • Left out. About 1,500 other extensions, shared libraries Comix does not use, and keiyoushi's issue templates and bots.
Hard to undo later

5 decisions

D1 · Which user agent to send

needs your answer · changes the spec

The spec says "always send iOS 18.5 Safari". New finding. Tachimanga's "Mobile Safari" setting already sends an iOS 26 Safari name tag (its changelog, 2025-11-18). Your Cloudflare pass was made with that iOS 26 tag.

A · Always force ours (spec)

…iPhone OS 18_5… Version/18.5 …
iOS 18.5 tag→does not match pass→Cloudflare may ask again

Risk. We could break a check that passes today.

B · Keep the app's tag if it is iPhone Safari (recommended)

app tag has "iPhone" + "Safari/" → keep it
otherwise → use our iOS 18.5 tag
iOS 26 tag→matches pass→Cloudflare stays passed

Still never sends the blocked "Default" tag. The error ends with ua: app or ua: forced.

D2 · Install link format

changes the spec

The spec says index.min.json. keiyoushi stopped using it. Today their index.min.json lists only a stub called "Outdated App". The real list is index.pb, and the files sit in GitHub Releases. Your official Comix came from that new format, so Tachimanga reads it.

Plan. Publish exactly keiyoushi's format. Your link becomes https://github.com/kenjixx1/manga-ext/raw/repo/index.pb.

The ID comes from the name. I checked the formula: it gives the live Comix ID exactly. Comix K has its own settings, so "Solve captchas" starts OFF there.

D4 · Keep the folder name src/en/comix

decided

The build tool has a setting called pkgName that changes the package without moving files. Same file paths as keiyoushi means future Comix fixes copy over with fewer clashes.

D5 · Public repo and your own signing key

decided in the spec
  • The repo must be public. Tachimanga cannot read private repos.
  • The key lives in ~/.manga-ext-signing/, outside the repo. Only 4 GitHub secrets made from it go online.
  • Please back that folder up. Without it, updates need uninstall and reinstall.
