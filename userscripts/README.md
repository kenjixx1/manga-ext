# Comix Tachimanga Skin

A Safari userscript that makes comix.to look and work like Tachimanga on an iPhone: Library with unread badges and
folder tabs, a Library / Browse / History / More bottom bar, a clean title page and a tap-to-show reader.

It only restyles and rearranges what comix.to already shows. It runs in Safari tabs, not in a Home Screen web app.

Install: open `comix-tachimanga.user.js` (raw link below) in Safari with the Userscripts app's extension turned on.

    https://raw.githubusercontent.com/kenjixx1/manga-ext/main/userscripts/comix-tachimanga.user.js
